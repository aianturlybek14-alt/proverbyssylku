# ПроверьСсылку: версия для Vercel

Страница `index.html` проверяет текст, ссылки, QR, фото и файлы прямо в браузере. Для разбора ИИ она обращается к `/api/check`, а тот уже обращается к Claude. Ключ хранится только на сервере Vercel.

## Запуск бесплатно (без карты)
Тариф Vercel Hobby бесплатный для личных проектов. ИИ тоже можно подключить бесплатно через Google Gemini.
1. Ключ: aistudio.google.com → Get API key. Платёжная карта не нужна.
2. Загрузите папку на GitHub и импортируйте репозиторий на vercel.com (New Project). Или выполните `npx vercel` в папке.
3. Settings → Environment Variables: добавьте `GEMINI_API_KEY`. Затем Redeploy.
4. Откройте адрес проекта и проверьте пример.

Без ключа тоже работает: проверка по правилам, файлы, флешка, QR, тренировка и советы. Блок ИИ покажет «недоступен».

**Важно о приватности.** На бесплатном тарифе Gemini Google может использовать присланные тексты для улучшения моделей, и их могут читать люди. Поэтому в странице есть галочка «Разрешить ИИ-разбор». Для платного тарифа условия другие.

**Платный вариант Claude.** Если позже появятся деньги, добавьте `ANTHROPIC_API_KEY` (console.anthropic.com), и функция переключится на Claude. Задайте там лимит расходов.

## Переменные окружения
| Имя | Зачем |
|---|---|
| `GEMINI_API_KEY` | бесплатный ключ Google |
| `GEMINI_MODEL` | по умолчанию `gemini-3-flash-preview`. Если упрётесь в лимит, попробуйте `gemini-3.1-flash-lite-preview` |
| `ANTHROPIC_API_KEY` | платный вариант (Claude). Если задан, используется он |
| `AI_PROVIDER` | `gemini`, чтобы принудительно выбрать Gemini |
| `ANTHROPIC_MODEL` | по умолчанию `claude-sonnet-5-5` |
| `ALLOWED_ORIGINS` | другие ваши сайты через запятую, которым можно вызывать `/api/check` |
| `RATE_LIMIT_PER_MIN` | запросов в минуту с IP, по умолчанию 6 |

Бесплатный лимит Google ограничен по запросам в минуту и в сутки, точные числа смотрите на aistudio.google.com/rate-limit. При превышении страница покажет «слишком много проверок».

## Использование из других проектов
Добавьте адрес сайта в `ALLOWED_ORIGINS` и отправляйте запрос:
```js
fetch('https://ВАШ-ПРОЕКТ.vercel.app/api/check',{method:'POST',headers:{'Content-Type':'application/json'},
 body:JSON.stringify({items:[{name:'сообщение',text:'Ваш счёт заблокирован, назовите код из СМС',rules:[]}],images:[]})}).then(r=>r.json())
```
Ответ: `verdict`, `risk`, `type`, `simple`, `kid`, `places`, `actions`, `reply`.

## Защита от злоупотреблений
- Лимит по IP в коде хранится в памяти и работает лишь частично. Для серьёзной защиты включите Vercel Firewall (Rate Limiting).
- Бесплатный лимит Google сам защищает от расходов, а при платном Claude задайте лимит расходов в консоли.
- Содержимое проверок функция не сохраняет и не логирует.

## Чтобы находили в Google
Зарегистрируйте адрес в Google Search Console и отправьте его на индексацию. Описание для поисковиков уже добавлено в `index.html`.
